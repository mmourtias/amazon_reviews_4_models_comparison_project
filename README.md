# Sentiment Analysis on Amazon Reviews

This project studies sentiment analysis on Amazon product reviews.
We compare four different approaches:

1. Word2Vec
2. GloVe
3. BERT (feature-based, no fine-tuning)
4. BERT fine-tuning

The experiments are implemented in Python using Jupyter Notebook.
